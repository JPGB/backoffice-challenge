# Backoffice Challenge

Projeto fullstack com CRUD de clientes.

# Linguagens

- Javascript/typescript
- Java 17

# Frameworks

- Frontend:

  - Angular 20
  - fontawesome
  - angular-oauth2-oidc

- Backend:
  - springboot
  - H2 (in-memory database)
  - rest

# Instruções

- Backend:
  Rode o comando mvn spring-boot:run na pasta back.

- Frontend:
  Rode o comando npm start na pasta front.
  Para logar utilize usuario: admin/admin ou logar com google.
